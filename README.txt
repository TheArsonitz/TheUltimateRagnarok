# TheUltimateRagnarok
Questo progetto rappresenta lo sviluppo di un gioco PvP/PvE. Nei vari file di unity si dovrà tenere a mente la seguente suddivisione:
  1. Cartella Scripts: qui vanno messi gli scripts di gioco (il codice in C#)
  2. Cartella Sprites: qui vanno messe le immagini relativi agli oggetti di gioco: personaggi, powerup, sfondi, ...
  3. Cartella Prefabs: qui vanno messi gli oggetti già configurati: forzieri, ...
  4. Cartella Scenes: qui vanno messe: arene, schermate di gioco, ...

Per i set di comandi si scelgono i seguenti:
  1. Salto: W - Accovacciata: S - Sinistra: A - Destra: D - Colpo: Space - Raccolta: E - Parata: S
  2. Salto: [8] - Accovacciata: [5] - Sinistra: [4] - Destra: [6] - Colpo: [0] - Raccolta: [7] - Parata: [5]
