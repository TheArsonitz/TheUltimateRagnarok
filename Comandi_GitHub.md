Come lavorare da ora in poi
1. Apri Unity Hub e clicca su Open. 
2. Seleziona la cartella del repository che hai appena clonato.
3. Lavora normalmente sul gioco.
4. Quando hai finito e vuoi inviarmi le modifiche:
	- Apri il terminale nella cartella del progetto,
	- git add . 	----> che serve a preparare i file,
	- git commit -m "Descrizione di cosa hai fatto"  	----> che serve a salvare le modifiche,
	- git push origin main ----> che serve a inviare tutto online.

5. Prima di iniziare a lavorare, ricordati sempre di scaricare le mie modifiche con:
	git pull origin main
